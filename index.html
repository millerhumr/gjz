方案摘要

本方案面向清流县总医院，以治未病科为核心，依托"AI 四诊硬件 + 中医大模型软件 + 全流程运营体系"，构建"1 个县域治未病中心 + N 个乡镇基层服务点"的县乡村一体化服务网络，打造集健康辨识、辨证评估、干预指导、随访管理、基层赋能、数据运营于一体的智慧治未病体系。

项目既满足国家治未病科建设标准，又贴合清流县实际需求，最终形成"总院有标杆、基层有服务、居民有获得感、管理有数据支撑"的县域治未病服务模式。

核心定位：务实落地 · 成效先行 · 分步推进。以 AI 技术赋能治未病科室建设与基层服务下沉，构建可持续的县域运营模式，实现社会效益与经济效益双重提升。

一、项目背景与市场分析

1.1 政策驱动：治未病成为县域中医药建设核心抓手

国家层面持续强化中医药"治未病"的战略地位。《中医医院治未病科建设与管理指南（2025 年修订版）》明确要求二级以上中医医院需独立设置治未病科，配备标准化的健康状态辨识设备，实现"健康评估-干预-追踪管理"一体化服务。科室面积、人员、设备均有硬性指标，治未病科不再是"可选项"而是"必选项"。

在县域医疗领域，《医疗卫生强基工程实施方案》提出，县级中医医院需发挥县域中医药龙头作用，牵头组建医共体，推动乡镇卫生院中医馆全覆盖，将治未病服务向基层下沉。《福建省紧密型医共体建设方案》同步推进，鼓励县域打造"预防-诊疗-康复"全链条中医药服务体系。

三明医改全国标杆，清流作为区域内率先启动治未病体系的县医院，具备打造示范项目的先发优势——第一个吃螃蟹的县医院，将获得政策、资金、品牌的三重红利。

📜
国家战略
《治未病科建设与管理指南》要求独立设科 + 标准化设备，实现健康评估→干预→追踪管理一体化。
🏗
县域部署
《强基工程》要求县中医院发挥龙头作用，牵头医共体，推动乡镇中医馆、村卫生室、社区卫生服务中心全覆盖。
🏛
省级落地
福建省紧密型医共体建设，鼓励县域打造预防→诊疗→康复全链条。三明医改标杆，先发优势窗口期。

1.2 行业现状：县域治未病普遍"有科室、弱能力"

当前县域中医医院治未病建设普遍存在四大共性问题：

🔄
服务同质化严重
多数医院仅配备基础体质辨识设备，服务项目集中在简单体检，缺乏差异化干预方案，难以形成科室特色与核心竞争力。
📉
基层能力断层
乡镇中医馆、村卫生室、社区卫生服务中心普遍缺乏专业中医师，仅能开展基础理疗，无法提供标准化的体质评估与健康指导，分级诊疗落地难。
💰
营收模式单一
收入主要依赖有限的诊疗服务收费，药食同源、养生干预等非医保项目开发不足，科室自我造血能力弱。
📊
数据价值未释放
健康数据分散在不同系统，缺乏统一沉淀与分析，无法支撑区域健康管理与科研转化，管理决策缺乏数据支撑。
三明区域研判：目前尚无标杆性县域治未病中心。清流县总医院率先启动治未病体系建设，具备打造区域示范项目的先发优势。

1.3 清流县本地需求研判

结合调研交流，清流县总医院治未病建设具备明确的 5 项现实诉求。治未病科目前仅有 1 名主治医师，同时承担门诊与管理工作，服务项目少、特色不显，亟待突破。

01
打造科室亮点
突破现有治未病科服务单一的现状，在三明市形成差异化特色，成为医院对外展示的名片科室。
02
区域辐射下沉
以总医院为核心，将服务延伸至下辖乡镇中医馆、村卫生室、社区卫生服务中心，统一诊疗标准，提升基层中医药服务能力。
03
兼顾效益创收
在公益服务基础上，通过药食同源产品、特色干预服务等方式，开辟科室新的营收增长点。
04
技术落地务实
对纯概念性临床系统持谨慎态度，更看重可落地、能见效、易操作的数字化工具。避免"重建设、轻使用"。
05
人才培养需求
治未病科人员配置有限，希望通过数字化工具减轻医生负担，同时实现经验沉淀与人才带教，让年轻医生快速成长。

二、核心痛点分析

2.1 医院端：科室发展缺抓手，服务能力待突破

👥
人力不足
仅 1 名主治医师承担门诊与管理，难以覆盖大量人群健康评估。
🧩
服务零散
三伏灸、体质辨识缺乏完整闭环，用户粘性低。
📐
标准不一
传统体质辨识依赖医生主观判断，服务质量难标准化。
💸
创收薄弱
营收结构单一，高附加值服务未充分开发。

2.2 基层端：服务能力薄弱，分级诊疗难落地

🎓
专业人才匮乏
乡镇中医馆、村卫生室人员中医基础薄弱，仅能提供基础理疗。
🛠
设备配置不足
缺乏标准化中医检测设备，无法获得用户信任。
🔗
上下联动缺失
基层与总院间缺乏数字化通道，分级诊疗停留在纸面。

2.3 民众端：认知不足，服务可及性差

💡
理念薄弱
县域居民"重治疗、轻预防"，对健康调理价值认知不足。
📍
获取不便
乡镇居民往返县城成本高，健康管理中断率高。
📋
千人一面
传统方案同质化严重，缺乏个性化日常指导。

2.4 管理端：数据沉淀不足，成效难以量化

🔌
数据孤岛
检测、诊疗、随访数据分散在不同系统，无法形成完整档案。
📊
缺乏抓手
无法实时掌握服务量、转化率、人群体质分布等核心数据。
📈
成效难量化
社会效益与经济效益缺乏直观数据呈现，不利于政策申报。

5.1 院内场景：公区筛查 + 治未病科标准化服务

院内场景采用"两台灵机四诊仪 + 两个部署位置"的策略：① 一台放在门诊大厅/导诊台/体检中心等公区，让普通用户（体检人群、就诊等候、家属陪护等）可以自行自助检测，作为免费智能导诊入口；② 另一台放在治未病科，作为科室标准化服务的一个环节（到院登记后由护士引导做四诊采集），承接公区导流来的精准客户。两个场景形成"公区自助引流 → 治未病科标准化承接"的院内闭环。

📍 部署位置 1：公区自助筛查入口（导诊台/体检中心/门诊大厅）
设备：1 台灵机四诊仪（公区专用）
面向：普通用户（体检人群、就诊等候、家属陪护等）自助检测，无需医护引导
定位：以免费中医体质检测为流量钩子，作为医院智慧服务入口。检测完成后直接引导到旁边的"调理商品区"（体质茶饮/汤包/膏方/艾灸贴等货架），让用户从"看完报告"到"顺手带一份调理产品"零摩擦（参考厦门中医院公区导流模式）
全流程：自助检测（3 分钟四诊+问诊）→ 自动报告 → 路径 A：自我健康管理（小程序节气养生+复查提醒）→ 路径 B：智能导诊挂号（按检测结果精准推荐科室）→ 路径 C：调理商品区现场选购（系统根据体质推送适配的药食同源产品）
产品：灵机四诊仪 + 智能导诊预问诊模块 + C 端小程序 + 调理商品区货架
📍 部署位置 2：治未病科标准化服务（核心承接）
设备：1 台灵机四诊仪（科室专用，与公区同型号）
面向：已完成公区自助检测并取得报告的客户；或专程到治未病科做深度服务的用户
定位：作为全院治未病服务的核心标杆，提供用户自助+智能引导的标准化服务流程（无需专人一对一陪同）
全流程：用户自助登记 → 自助四诊采集 → 报告生成 → 三路径引导（详见下方流程）
产品：灵机四诊仪 + 治未病管理系统 + C 端小程序

治未病科标准化服务 5 步流程（用户自助 + 智能引导）

01
自助四诊采集

02
数据同步 + AI 评估

03

用户查看报告后，系统根据体质智能推荐：

路径 B：找医生 → 解读报告 + 必要的调理服务（膏方/三伏灸等）
04
医生服务（按用户选择）
选 B 的用户 → 医生结合用户分析检测报告，出具个性化调理方案（含膏方/三伏灸/经络调理等）
05
持续健康跟踪
系统定期推送复测提醒（节气/季度），动态调整方案
✨
用户自助 + 智能引导
无需专人一对一陪同，用户自主完成检测 + 查看报告 + 选择下一步路径，大幅降低科室人力投入。
🎯
三路径智能推荐
报告生成后根据体质自动推荐 3 条路径（商品区/医生解读/直接调理），不同需求不同转化方式。
🔄

七、系统部署与对接方案

私有化部署方案

  • 部署模式：支持完全院内私有化部署，所有模型、数据、业务系统均运行在医院本地服务器，物理隔离，数据不出院。
  • 信创适配：兼容麒麟、统信等国产操作系统，支持鲲鹏、海光芯片，满足医院信创建设要求。
  • 安全机制：配备数据加密、权限管控、日志审计等安全机制，保障医疗数据安全。
  • 服务器配置：推荐采用四服务器集群私有化部署架构（应用服务器 4核16G / 算法服务器 16核32G / 存储服务器 4核16G / 前置服务器 4核16G）。支持利旧医院现有硬件资源。
